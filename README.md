# DiskCheck

**Портативная утилита проверки здоровья дисков (SSD/HDD) для Windows.**
SMART-атрибуты, износ, температура, ошибки, объём записи и итоговый вердикт по каждому диску — без установки, без сторонних программ, с дисками любых производителей.

## Что умеет

- 🩺 **SMART-таблица целиком** — ID, значения, raw-счётчики с расшифровкой
- 📉 **Износ и ресурс SSD** — Wear (%), SSD Life Left, счётчики записи
- 🌡️ **Температура и наработка** в часах
- ⚠️ **Ошибки**: переназначенные секторы (05), pending-секторы (C5), неисправимые (C6), CRC-ошибки кабеля (C7), прогноз сбоя SMART
- 📊 **Объём записи**: сколько ГБ записал хост, сколько ушло в NAND, и **WAF** (коэффициент усиления записи)
- ✅ **Итоговый вердикт** по каждому диску: ЗДОРОВ / есть замечания — с пояснением, что проверить
- 📈 **Журнал измерений** `DiskCheck_history.csv` — история запусков, динамика в Excel
- 🏴‍☠️ Пиратская иконка — потому что хорошие диски не должны тонуть

## Быстрый старт

1. Скачайте репозиторий: зелёная кнопка **Code → Download ZIP** (или `git clone`)
2. Распакуйте в любую папку
3. Двойной клик по **`DiskCheck.bat`**
4. В окне UAC нажмите **«Да»** (чтение SMART требует прав администратора)
5. Читайте результат — вердикты в рамках внизу

Требования: Windows 7+ с PowerShell (уже встроен в систему). Ничего устанавливать не нужно. Утилита только **читает** данные дисков и ничего в системе не меняет.

## Как читать результаты

| Показатель | Норма | О чём говорит |
|---|---|---|
| Износ (Wear) | 0–10% отлично, 10–50% норма, выше — следите за бэкапами | выработанный ресурс NAND |
| Температура | до 60 °C | перегрев ускоряет деградацию SSD |
| 05 Reallocated, C5 Pending, C6 Uncorrectable | 0 | физические проблемы поверхности/NAND |
| C7 UltraDMA CRC | 0 | плохой SATA-кабель или порт |
| WAF | 1.0–2.0 | во сколько раз контроллер пишет больше хоста; заметно выше — повод насторожиться |
| Прогноз сбоя SMART | нет | сам диск предсказывает скорый отказ |

Счётчики записи 241/242 у многих SSD (KingSpec, часть Kingston и других) считаются блоками по 32 МБ — DiskCheck учитывает это автоматически. У других прошивок единицы могут отличаться, ориентируйтесь на динамику между запусками.

## Журнал измерений

При каждом запуске строка результатов дописывается в `DiskCheck_history.csv` рядом со скриптом (разделитель `;`, открывается в Excel): дата, диск, серийник, износ, температура, наработка, объём записи, ошибки, вердикт. Запуская проверку раз в месяц, вы увидите динамику износа и счётчиков записи.

## Совместимость и деградация

Утилита рассчитана на «запустил — работает» на любой машине:

| Окружение | Поведение |
|---|---|
| Windows 10/11 + права администратора | полный режим: Storage API + SMART + вердикты |
| Windows 7/8, PowerShell 2.0 | списки дисков из WMI, часть таблиц пропускается |
| Без прав администратора | утилита сама перезапускается с UAC; при отказе — только базовые данные |
| USB/внешние диски | видны в списке; SMART обычно отдаётся только у SATA/NVMe |
| Нет ни одного источника данных | честный красный итог с подсказкой, что не так |

## Скрытые параметры (отладка)

```bat
DiskCheck.ps1 -SkipElevation   :: не запрашивать UAC (для теста)
DiskCheck.ps1 -NoPause         :: не ждать Enter в конце
```

## FAQ

**Зачем права администратора?** Чтение SMART идёт через драйвер хранилища, а он пускает только администраторов.

**Windows или антивирус предупреждает при запуске.** Файлы без цифровой подписи — обычное дело для скриптов. Код открыт, можно проверить; при предупреждении SmartScreen выберите «Выполнить в любом случае» или снимите блокировку в свойствах файла.

**Утилита что-то меняет на дисках?** Нет. Только читает SMART и пишет собственный журнал CSV рядом с собой.
